# 冲突设计（示例）

## 五大冲突类型

| 类型 | 说明 | 举例 |
|------|------|------|
| 人际 | 人与人目标对立 | 婆媳、职场对手 |
| 内心 | 角色自我撕裂 | 道义与利益 |
| 环境 | 处境压力 | 贫穷、期限 |
| 社会 | 规则与偏见 | 阶层、身份 |
| 命运 | 意外与巧合 | 疾病、事故 |

## 升级三步法

1. **加压** —— 让代价变大
2. **收窄** —— 让退路变少
3. **摊牌** —— 迫使角色做出选择

## 检验标准

> 如果这场戏删掉，剧情完全不受影响 —— 那它就不该存在。

> 示例规则，请按你的创作体系替换。
