# 剧本格式规范（示例）

## 场景标题

```
第 N 集  第 M 场
场景：<地点>    时间：<日/夜>    人物：<出场人物>
```

## 正文格式

- **动作描述**：左对齐，现在时，只写镜头能拍到的东西
- **人物名**：独立成行，后接对话
- **对话**：紧接人物名下一行
- **画外音 / OS**：标注 `（画外音）`
- **字幕 / 短信**：标注 `【字幕】`

## 硬性约束

- 不写镜头号与景别（由导演处理）
- 不写演员情绪指令（用动作呈现）
- 单句台词建议不超过 25 字
- 一场戏建议不超过 2 分钟

> 示例规则，请按你的创作体系替换。
