# 钩子类型库（示例）

## 集首钩

- **结果前置**：先给最炸的结果，再倒叙原因
- **异常开场**：以不合理的事件切入
- **悬念提问**：抛出一个必须回答的问题

## 中段钩

- **信息差**：观众知道，角色不知道（或反之）
- **倒计时**：给出明确期限
- **新变量**：引入意料之外的人物或事件

## 集末钩

- **反转揭示**：颠覆观众已有认知
- **身份揭露**：隐藏身份曝光
- **二选一**：把角色逼到必须抉择的关口
- **危机降临**：直接抛出威胁

## 使用建议

- 每集至少 3 个钩子（集首 / 中段 / 集末）
- 同一类型钩子不要连续两集重复

> 示例规则，请按你的创作体系替换。
